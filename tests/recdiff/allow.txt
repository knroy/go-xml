# Differences tests/recdiff compare accepts between two recordings; see the
# rule format in tests/recdiff/main.go and docs/testing.md, "Output
# differential". Every rule names the behaviour change it admits. A rule that
# matches nothing is reported with 0 cases and should be removed.

# generate-id strings are implementation-dependent (XPath F&O 3.1 §14.6.4) and
# change with the node record: N<tree>x<order>.
* * N\d+x\d+

# The XSLT suite harness does not fix fn:current-dateTime (the QT3 one does,
# and tests/record.sh passes -now), so a stylesheet that writes the clock
# writes a different instant each run: evaluate-052, cvt-042.
xslt* * \d{4}-\d\d-\d\dT\d\d:\d\d:\d\d\.\d+Z

# xsl:product-version answers the module version (internal/version), and
# DocBook and the Schematron reports write it into their output: recordings
# made either side of a release differ there by design.
* * go-xml[ /]\d+\.\d+\.\d+
xslt30 document/document-2011 prod="\d+\.\d+\.\d+"
